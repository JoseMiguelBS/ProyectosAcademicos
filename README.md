## Antes de ejecutar

Algunos proyectos se conservaron en su formato comprimido original (`.rar` o `.7z`) porque no se pudo verificar su contenido interno en este proceso. Descomprímelos localmente y agrega un README específico cuando confirmes su lenguaje, dependencias e instrucciones.

Los proyectos ZIP que sí se pudieron revisar se organizaron conservando el código fuente y retirando ejecutables y archivos compilados que normalmente no es necesario versionar.

## Recomendaciones

- Revisa que no haya contraseñas, tokens, claves API ni datos personales.
- No publiques archivos de bases de datos con información real o privada.
- Completa el README de cada proyecto con objetivo, funcionalidades, tecnologías, instalación y capturas.
- Mantén los archivos originales hasta comprobar que la organización quedó correcta.
